# Contributing to Sleepy Ducks

Thanks for wanting to help. This is a small one-person game, so small, focused pull requests are easiest to review.

## Good places to start

- Bugs you hit while playing, especially on phones.
- Gameplay ideas: open an issue first and describe how it would feel to play.
- Performance on older phones. See [`MOBILE_PERF_TESTING.md`](./MOBILE_PERF_TESTING.md).

## Getting set up

```bash
npm install
npm run dev
```

Use Chrome's device toolbar in portrait to test.

## A few rules

- Keep gameplay changes and art or audio changes in separate PRs.
- Don't add new art or audio unless you made it or it's clearly free to use. Say where it came from.
- Describe what you changed and how you tested it.

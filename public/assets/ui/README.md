# UI assets

Place menu/UI images here (served at `/assets/ui/…`).

| File | Used for |
|------|----------|
| `gear.png` | Settings button (top-right on menu / game over) |
| `logo.png` | PWA / favicon / home-screen app icon source |
| `title-logo.png` | Menu title |
| `home-waterfall.png` | Menu background |
| `play.png` / `retry.png` | Play / retry buttons |
| `heart.png` | HUD lives |
| `game-over.png` | Game over banner |

**Settings gear:** copy your wood `gear.png` into this folder as `gear.png` (not `sprites/ui/`).
